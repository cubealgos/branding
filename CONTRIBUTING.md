# Contributing

This repository holds the Cube Algos brand under **two licences**: code is Apache-2.0 + CLA, brand
assets are all rights reserved. See the README's "Licence" section and `NOTICE`.

## Code contributions

- **Sign the CLA** (`CLA.md`) in your first pull request, before it can be merged.
- **Open an issue first** for anything non-trivial. Small fixes can go straight to a PR.
- **One PR, one concern.** Work on a branch, never directly on `development` or `production`.
- Every code file carries `SPDX-License-Identifier: Apache-2.0`.
- Do not report a suspected vulnerability in a public issue or PR; see `SECURITY.md`.

## Brand-asset contributions

Logos, the wordmark, the mascot, favicons, stings and animations are owned by Cube Algos UG
(haftungsbeschränkt) and are not open for outside reuse (`assets/LICENSE.md`). A contribution to
an asset is accepted **only as a gift of the rights to Cube Algos UG (haftungsbeschränkt)**: you
transfer all rights in it to the company, and it then falls under `assets/LICENSE.md`, not
Apache-2.0. The CLA does not cover this; agree it in writing with hello@cubealgos.de before
sending the work. Asset files never carry an Apache-2.0 header or SPDX tag.
