# Onest ExtraBold (800)

The source font for the outlined wordmark (`scripts/lib/logo.mjs`). Onest is
copyright 2021 The Onest Project Authors, licensed under the SIL Open Font
License 1.1 without a Reserved Font Name (`OFL.txt`); using and modifying it,
including this instance, is allowed under that licence.

`Onest-ExtraBold.ttf` is the wght=800 instance of the upstream variable font
`ofl/onest/Onest[wght].ttf` of <https://github.com/google/fonts> (upstream ships no
static files), made with fontTools 4.66.1:

```sh
fonttools varLib.instancer 'Onest[wght].ttf' wght=800 -o Onest-ExtraBold.ttf --update-name-table
```

This directory is the build input of the wordmark and is not a brand asset; the
Apache-2.0 licence of the repository does not cover it, the OFL does.
